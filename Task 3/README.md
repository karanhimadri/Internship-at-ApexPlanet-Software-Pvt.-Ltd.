# Task 3 – Advanced Styling & JavaScript

This repository contains **Task 3** of the **Web Development Internship (HTML, CSS & JavaScript)** at **ApexPlanet Software Pvt. Ltd.**

The objective of this task is to gain **advanced frontend skills** by implementing responsive design, interactive JavaScript components, and fetching real-time data from a public API.

---

## 📌 Task Objective

- Apply **responsive design** using CSS media queries
- Build **interactive JavaScript components** (Quiz)
- Fetch and display **real-time data from a public API**
- Strengthen DOM manipulation and JavaScript logic

---

## 🛠️ Technologies Used

- **HTML5** – Structured layout for quiz and API sections
- **CSS3** – Advanced styling, Flexbox layout, and media queries
- **JavaScript (ES6)** – Quiz logic, DOM manipulation, and API fetching using `fetch()`

---

## 📂 Project Structure

```bash
task-3/
│── index.html
│── style.css
│── script.js
```

---

## ✨ Features Implemented

- Fully responsive layout using CSS Flexbox and media queries
- Interactive JavaScript quiz with:
  - Multiple-choice questions
  - Score calculation
  - Dynamic question rendering
- API integration to fetch and display random jokes dynamically
- Clean and user-friendly UI without using any frameworks

---

## ▶️ How to Run the Project

- Download or clone this repository
- Open index.html in any modern web browser
- Attempt the quiz questions and view your score
- Click the button to fetch a random joke from the API
