## 💾 Data Persistence

### Local Storage Usage

**To-Do App:**
- Stores tasks in `localStorage` under key `'todos'`
- Stores notes in `localStorage` under key `'notes'`
- Data structure: Array of objects with properties (id, text/title, content, category, etc.)

**Product Listing:**
- Stores cart items in `localStorage` under key `'cart'`
- Persists across browser sessions
- Updates automatically on cart changes

### Clearing Data
To reset any app data
