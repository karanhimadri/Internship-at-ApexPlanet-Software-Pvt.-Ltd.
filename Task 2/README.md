# Task 2 – Intermediate HTML, CSS, and JavaScript

This section contains **Task 2** of the **Web Development Internship (HTML, CSS & JavaScript)** at **ApexPlanet Software Pvt. Ltd.**

The objective of this task is to strengthen **intermediate-level frontend skills** by building responsive layouts, implementing form validation, and performing dynamic DOM manipulation using JavaScript.

---

## 📌 Task Objective

- Build structured and styled **HTML forms**
- Implement **JavaScript-based form validation**
- Create **responsive layouts** using Flexbox and CSS Grid
- Perform **DOM manipulation** for dynamic content updates

---

## 🛠️ Technologies Used

- **HTML5** – Forms, inputs, semantic elements
- **CSS3** – Flexbox, Grid, media queries for responsiveness
- **JavaScript** – Event handling, validation logic, DOM manipulation

---

## 📂 Project Structure

```bash
task-2/
│── index.html
│── style.css
│── script.js
```

## ✨ Features Implemented

- Contact form with name, email, and message inputs
- Client-side form validation using JavaScript
- Responsive two-column layout using CSS Grid
- Mobile-friendly layout using media queries
- Dynamic to-do list allowing users to add and remove tasks

---

## ▶️ How to Run the Project

- Download or clone this repository
- Navigate to the task-2 folder
- Open index.html in any modern web browser
- Test form validation and to-do list functionality
