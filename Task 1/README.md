# Task 1 – Basics of Web Development

This repository contains **Task 1** of the **Web Development Internship (HTML, CSS & JavaScript)** at **ApexPlanet Software Pvt. Ltd.**

The objective of this task is to learn and apply the **foundational concepts of web development** using HTML, CSS, and JavaScript.

---

## 📌 Task Objective

- Understand basic **HTML structure and elements**
- Apply **CSS styling** for layout and visual design
- Add **basic JavaScript interactivity**

---

## 🛠️ Technologies Used

- **HTML5** – Semantic structure (`nav`, `main`, `section`, `footer`)
- **CSS3** – Styling, layout, and hover effects
- **JavaScript** – Basic interactivity using event handling

---

## 📂 Project Structure
```bash
task-1/
│── index.html
│── style.css
│── script.js
```
---

## ✨ Features Implemented

- Semantic and professional HTML layout
- Clean and responsive UI styling with CSS
- Interactive button triggering a JavaScript alert
- Navigation bar and multiple content sections

---

## ▶️ How to Run the Project

1. Download or clone this repository
2. Open `index.html` in any modern web browser
3. Click the button to see JavaScript interactivity
